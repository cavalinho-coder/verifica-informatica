La struttura client server vede due principali ruoli:
il client: che domanda un servizio, http request.
il server: che risponde ed invia il servizio richiesto: http response.

la struttura client-server puo' essere organizzata in modo standard oppure in p2p:

il peer to peer è invece un sistema dove il server offre dei punti di attacco, degli "endpoint" predefiniti, ed il client mandando requests a questi endpoint riceve una risposta predefinita.
